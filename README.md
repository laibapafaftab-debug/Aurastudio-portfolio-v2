# AuraStudio — Portfolio

Web apps and AI automation, built and deployed by Laiba Aftab.

**Live site:** https://laibapafaftab-debug.github.io/custom-web-demo/

## What this is

A single-page portfolio site for AuraStudio, showcasing full-stack web development and AI automation work for small businesses and founders.

## What's on the page

- Hero introduction and core offer
- Services: web applications, AI/API integrations, automated lead pipelines
- Featured work: AI Lead Widget, Lead Automation Demo, this site itself
- How I work: a short, predictable 4-step process
- About / bio
- Contact form (via [FormSubmit](https://formsubmit.co)) that emails inquiries directly

## Stack

- HTML, CSS, vanilla JavaScript (no build step, no framework)
- Google Fonts: Space Grotesk, IBM Plex Sans, IBM Plex Mono
- Contact form powered by FormSubmit (no backend required)
- Hosted on GitHub Pages

## Editing this site

Everything lives in a single `index.html` file — styles and scripts are inline, so there's nothing to build or install. To make changes:

1. Edit `index.html` directly (in GitHub's web editor, or clone the repo locally).
2. Commit the change.
3. GitHub Pages redeploys automatically within a minute or two.
